# 局内属性与技能调整

故事进行中，主持人打开房间右侧「角色调整」，选择已载入角色卡的玩家。也可以点击圆桌席位或同桌伙伴，在人物详情里打开「调整属性与技能」。手机从「局内工具」进入。准备阶段此面板仅供查看，请用制卡器编辑并审核角色卡。

## 数值怎样生效

| 数值 | 含义                                               |
| ---- | -------------------------------------------------- |
| 原始 | 制卡时的属性与技能；保留原来的分配账本             |
| 长期 | 原始值加主持人记录的成长、永久损伤等调整           |
| 生效 | 长期值再计入所有已启用的临时效果；角色检定使用此值 |

### 修改长期值

选中属性或技能，切换到「长期数值」，填写希望保留的数值和可选原因。保存后会同步给房间成员，附上公开日志。「重置长期修正」只移除此项目的长期变更，其他项目与临时效果仍然保留。

D&D 的技能由当前关联属性与原有熟练／专精计算，再叠加技能修正。比如敏捷 18、隐匿原本 +4，将长期隐匿填成 +6 后相当于额外 +2；之后敏捷临时降至 14，隐匿变为 +4。暂时停用敏捷惩罚后隐匿回到 +6。技能的长期输入值不包含临时属性变化。

CoC 的成长按技能目标百分比记录。例如侦查从 50 成长至 60，不需要回到制卡器重新分配职业点或兴趣点。局内 DEX、EDU 变化不重算已经习得的闪避、母语技能；需要改变时由 KP 分别调整。

### 添加临时效果

选中项目，填写正负修正和效果名称，可用快捷数值按钮。例如「视野开阔」为侦查 +15，结束条件填写「离开瞭望台时」。保存前会预览最终生效值。

效果保存在面板下方，可停用、重新启用或移除。「清除全部」会在确认后移除所有临时效果，保留长期变化。结束条件是提醒文字，不是自动计时器；换场景、过回合、暂停、刷新网页或重启服务器都不会自动结束效果。多个效果只做加减叠加，主持人负责判断某条规则是否允许叠加。

## 联动与范围

- 属性／技能检定和 D&D 属性豁免使用最新生效值。CoC 自动刷新普通、困难与极难目标。
- 重新排定先攻时使用最新敏捷；进行中的行动顺序保留原来的结果。
- 战斗面板的玩家体质检定、D&D 专注豁免默认值、CoC 近战进攻／闪避／反击默认值使用当前角色数值。主持人手填覆盖时保留手填值，可点「使用角色最新加值」或「使用角色当前…技能」恢复跟随角色。
- D&D 攻击加值仍是手填总加值，因为这里没有自动选择武器、施法属性或装备。
- 局内数值修正不自动修改 HP、MP、SAN、资源上限或 AC，也不自动触发死亡、法术与状态规则；例如 CoC 神话技能变化后的 SAN 上限，仍需主持人另行核对。
- 当前工具针对**玩家角色**。NPC／怪物的备团模板与本场实例仍使用主持人工具集及战斗面板。

生效与长期数值都检查整数边界：D&D 属性 1–30、技能加值 −100–100；CoC 属性 0–100、技能 0–100，神话最多 99。临时效果每项修正 −100–100，每张角色卡最多 30 个效果。停用或移除一个效果若令其他叠加后的总值越界，操作会被拒绝；可清除全部临时效果回到有效的长期值。

制卡的分配预算和剧本限制用于**原始制卡记录**。局内成长与临时效果由主持人裁定，不会反过来消耗制卡点。返回准备阶段仍会清空所有审核与准备状态，保留修正记录；主持人应在审核页同时核对原始分配与修正。

## 保存与导出

局内每次调整即时保存到房间，并公开记录于房间日志（仍遵循最近 300 条的保留范围）。与其他局内操作一样，修改时检查角色身份与版本；过期草稿不能覆盖别的窗口刚完成的操作。

玩家可从「我的角色」导出最新 JSON，人物详情也提供导出。完整卡片可以在制卡器导出 Markdown。文件保留原始属性／技能、原始分配、长期变化与临时效果，下次导入不会重复叠加。个人角色档案不会自动被房间里的变化覆盖，请导出最新卡片后再导入档案。重新入房的导入卡必须经过主持人审核。

### 文件字段

现有 `schemaVersion: 1` 人物卡增加可选 `adjustments`，没有此字段的旧卡仍然可用。这个字段只记录数值变化；不要把生效投影写回原始 `attributes` 或 `skills`。

```json
{
  "adjustments": {
    "permanent": [{ "target": "skill", "key": "spotHidden", "amount": 10, "reason": "幕间成长" }],
    "temporary": [
      {
        "id": "clear-view",
        "name": "视野开阔",
        "endCondition": "离开瞭望台时",
        "enabled": true,
        "changes": [{ "target": "skill", "key": "spotHidden", "amount": 15 }]
      }
    ]
  }
}
```

这是字段片段，不能单独作为人物卡导入。完整文件仍须含角色身份、原始属性、技能与分配记录等必需字段。导入的修正会出现在审核页；导入本身不会获得审核通过。
